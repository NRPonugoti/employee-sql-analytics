
# 📊 Employee Salary Analytics using SQL

## 🚀 Project Overview
This project demonstrates advanced SQL skills using **Window Functions** to analyze employee salary data and generate business insights.

---

## 🎯 Objectives
- Identify top-paid employees per department
- Compare salaries across employees
- Analyze salary trends
- Perform ranking and grouping analysis

---

## 🛠️ Tech Stack
- SQL (MySQL / PostgreSQL / SQL Server)

---

## 📂 Dataset
Employee table with:
- employee_id
- employee_name
- department_name
- salary

---

## 🔥 Key SQL Concepts Used
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- LAG()
- LEAD()
- PARTITION BY
- ORDER BY (Window functions)

---

## 📊 Business Use Cases

### 1. Top 3 Employees by Salary per Department
### 2. Salary Comparison (Higher / Lower / Same)
### 3. First Employees Joined per Department
### 4. Salary Trend Analysis

---

## 📈 Sample Insights
- Identified highest-paid employees in each department
- Compared salary growth trends
- Detected salary gaps between employees

---

## 💼 Resume Description

Developed a SQL analytics project using advanced window functions such as ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), and LEAD() to analyze employee salary data.  
Implemented solutions for ranking, trend analysis, and salary comparison across departments.
